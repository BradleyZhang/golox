goLox

A Go implementation of the Lox interpreter from Crafting Interpreters.

This is a learning project built alongside my reading of the book.

WIP

Reference: https://craftinginterpreters.com/

## Run
Build
```bash
go build
```

Run a lox source file:
```bash
./golox <path>
```

Run the interactive REPL:
```bash
./golox
```
